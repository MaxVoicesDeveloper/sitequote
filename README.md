# SiteQuote

**SiteQuote** - открытый калькулятор стоимости разработки сайтов.

### Меньше общения. Больше подготовленных заявок.

Клиенту больше не придётся начинать общение с менеджером с нуля. Он самостоятельно выбирает необходимые услуги, указывает пожелания и получает предварительную оценку стоимости.

Это экономит время обеих сторон и позволяет получать уже подготовленные заявки с пониманием потребностей и бюджета клиента.

### Гибкая настройка под себя

Стоимость услуг, доступные функции и параметры расчёта можно настраивать самостоятельно.

SiteQuote можно внедрить на личный сайт или сайт компании, адаптировав интерфейс под собственный бренд.

Проект имеет открытый исходный код, поэтому его можно изменять и развивать под свои задачи.
